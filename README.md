# Janice Seelan Music Studio

Hum a tune into your phone. Hear it played on real instruments. Layer it into a whole song.

- Record inside the app (hum → instrument, or keep your voice)
- 26 sampled instruments: symphony strings, solo violin, violin section, cello, harp, flute, horn, trumpet, guitars, bass, sitar, shehnai, piano and more
- Real drum kit and tabla (Teentaal, Keherwa, Dadra, Rupak, Jhaptaal), tanpura drone
- Make your own instrument from a clip of any song
- Tune helper: chords, bass line, harmony, continue a melody, new melodies in ragas
- Piano-roll note editor, mixer with volume, pan and reverb, undo
- Export: WAV (24-bit / 32-bit float / CD), MP3 320, stems, MIDI, song backup
- Works offline once installed

## Install on Android
Open the app link in Chrome → menu (⋮) → **Install app**.

See `CLAUDE.md` for how the code is organised.
